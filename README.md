## 🚀 **Quick Start**

</div>

<br/>

<div align="center">

| ⚙️ **Requirement** | 📌 **Version** |
|:---:|:---:|
| Any modern browser | Chrome / Firefox / Edge |
| Code editor | VS Code (recommended) |
| No build tools | Zero setup required ✨ |

</div>

<br/>

### 📦 **Installation**

```bash
# Clone the repository
git clone https://github.com/LeGenDX96/Portfolio.git

# Enter the folder
cd Portfolio

# Open in browser (Windows)
start index.html

# Open in browser (Mac)
open index.html

# Open in browser (Linux)
xdg-open index.html
```

<br/>

<div align="center">

## 🌐 **Deploy Anywhere**

</div>

<br/>

<details>
<summary><b>🐙 &nbsp;GitHub Pages (Free & Easy)</b></summary>

<br/>

1. Push code to GitHub
2. Go to **Settings** → **Pages**
3. Under **Source**, select `main` branch
4. Click **Save**
5. Done! Live at → `https://LeGenDX96.github.io/Portfolio`

</details>

<details>
<summary><b>▲ &nbsp;Vercel (Recommended)</b></summary>

<br/>

1. Go to **[vercel.com](https://vercel.com)**
2. Click **New Project** → **Import Git Repository**
3. Select your portfolio repo
4. Click **Deploy**
5. Live in ~30 seconds ⚡

</details>

<details>
<summary><b>🟢 &nbsp;Netlify (Drag & Drop)</b></summary>

<br/>

1. Go to **[netlify.com/drop](https://app.netlify.com/drop)**
2. Drag your portfolio folder
3. Done! Instantly live 🎉

</details>

<details>
<summary><b>🔷 &nbsp;Render (Static Site)</b></summary>

<br/>

1. Go to **[render.com](https://render.com)**
2. **New +** → **Static Site**
3. Connect GitHub repo
4. **Publish Directory:** `.`
5. Click **Create Static Site**

</details>
